# Multi-Agent-Dispatch
The topic we have chosen to research, based on Urban Transportation, is an Explainable Multi-Agent Ride-Sharing Dispatcher. This focuses on problems faced by drivers and passengers in apps like Uber and Lyft, where riders and drivers are not always optimally matched.

We plan on using Nyc TLC and use a subset of manhathan to formulate how agent dispatchers would work in a petting zoo environment.
